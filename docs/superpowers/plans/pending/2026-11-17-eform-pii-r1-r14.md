# eForm dùng bộ che PII R1–R14 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trợ lý lâm sàng trên eForm `/` che dữ liệu nhạy cảm bằng bộ `pii-auto-1`. Chuỗi xử lý: R1–R8 che, R10 gán nhãn, R11 chốt chặn, R12 tối thiểu dữ liệu, R13 ghi nhật ký, R14 lấy đồng ý từ hồ sơ. Luồng đúng như trang "Phần chung" của `docs/so-do/luong-chinh.drawio`.

**Architecture:**
- Giữ nguyên ticket, binding, phiên ghi âm và bản chép lời bất biến.
- Thay ruột `PrivacyTickets`: hai bước `prepare`/`approve` (regex `local-review-2` + bác sĩ duyệt tay) gộp thành một hành động `check`. Hành động này chạy `redactPii` → `checkResidualPii` → đọc cờ đồng ý. Qua chốt chặn thì cấp ticket `passed`, bị chặn thì trả lý do.
- Bước trích xuất nhận bằng chứng `deidentification` do máy chủ dựng, rồi ghi nhật ký R13.
- Giao diện bỏ ô tích đồng ý và ô sửa bản đã che. Thay bằng bản đã che chỉ đọc, số mục che theo rule và lý do chặn.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, zod, test `node:test` qua `tsx --conditions=react-server`.

**Spec:** [2026-11-17-eform-pii-r1-r14-design.md](2026-11-17-eform-pii-r1-r14-design.md). Bảng rule R1–R14 và căn cứ pháp lý: [2026-11-16-demo-luong-du-lieu-design.md](2026-11-16-demo-luong-du-lieu-design.md), mục rule.

**Interfaces:**
- Consumes: `redactPii`, `checkResidualPii`, `aiRouteFor`, `PII_POLICY_VERSION` và các kiểu từ `@/shared/clinical/pii`.
- Produces:
  - `PrivacyTickets.check(text: string, mode: SpeakerMode, input: { known: KnownIdentifier[]; allowlist: ReadonlySet<string>; consent: boolean; binding?: PrivacyBinding }): PrivacyCheck`.
  - `interface PrivacyCheck { status: "passed" | "blocked"; ticket: string | null; preview: string; counts: Record<PiiRule, number>; gate: GateResult; ai_route: AiRoute; expires_at: string | null }`. Export kiểu này.
  - Thứ tự xử lý trong `check`:
    1. `checkText`, kiểm tra chế độ.
    2. Có nội dung cấp 3 (`hasRestrictedContent`) thì ném `ClinicalError` 403.
    3. `redactPii`, rồi `checkResidualPii(clean, known, allowlist)`.
    4. Bị chặn: **không lưu entry**, trả `ticket: null`, `expires_at: null`.

  - `reviewed(ticket, binding)`: giữ nguyên.
  - `pii(ticket: string, binding?: PrivacyBinding): { counts: Record<PiiRule, number>; ai_route: AiRoute; consent: boolean; clean_sha256: string }`. Hàm này đọc entry (hết hạn thì ném lỗi như `read`).
  - Xóa `prepare`, `approve`, mảng `syntheticIdentifiers` và import `ca-gia.json`.
